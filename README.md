# Loja Artlumi

Página provisória, estática e em português para `store.artlumi.com.br`. Funciona sem build, JavaScript ou bibliotecas externas.

## Publicação

No GitHub, configure **Settings → Pages** para publicar a branch `main` pela pasta **/ (root)**. O arquivo `CNAME` define o domínio personalizado.

Quando a Loja Virtual do Bling for liberada, altere o CNAME no Registro.br para apontar ao destino informado pelo Bling.
